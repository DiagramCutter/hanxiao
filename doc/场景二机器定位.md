# 场景二机器定位

场景二的铣槽机按 `GET /scene/drilling` 返回的 `pileName` 定位。`SceneForkliftIndex.vue` 只创建一次 `useSceneDrilling`，同一份响应同时更新施工数据面板和机器；沿用立即请求、每 20 秒刷新及卸载中止请求的规则。

## 孔位和锚点

`src/views/SceneForklift/machinePlacement.ts` 保存模型的九个物理孔位。根据 PDF 标注和确认的九铣排列，沿场地原始坐标 `+Z` 依次为：

`S1-1、S1-3、S1-2、S2-1、S2-3、S2-2、S3-1、S3-3、S3-2`。

当前场地为 `hcangdi2-compressed.glb`，沿用旧场地 `changdi020629` 的九槽标定。十道边界的 Z 坐标为 `1.338959、4.245124、7.151249、10.057379、12.963510、15.869640、18.775765、21.681890、24.588025、27.494170`。每两道边界的中点即一个孔位；槽内中心轴 X 为 `21.14148`，地面 Y 为 `-1.94129`。旧模型已移除，运行时不依赖它。

定位锚点取 `xitoujiglb` 的 `xitou02 / material8` 底部铣轮中心，原始坐标为 `(-5.304758284, -1.664483527, 0.002397469)`，用其水平工作轴对准槽内中心。保留现有机器方向、比例和调校后的离地高度，并随场地的倾斜高度移动。

当前场地加载后先通过节点 `231` 的世界矩阵逆变换恢复业务坐标，再使用固定标定中心 `[12.353393, -0.032455, 0.000004]` 居中。机器仍按加载后的包围盒居中。场地孔位和机器工作轴分别减去各自中心，再应用对应变换。当前机器 wrapper 直接挂在 Three.js Scene 下。

## 更新行为

- 模型加载完成后立即读取最新 `pileName`，覆盖接口先返回和模型先加载两种情况。
- 孔号更新时移动现有机器，不重复加载模型或创建接口轮询。
- 接受九个固定孔号，兼容小写和首尾空格；空值或其他孔号暂时隐藏机器，恢复有效孔号后重新显示。
- 三维机器只联动地面孔位；成孔深度和施工状态可在页面及槽孔状态弹窗查看。

后续若替换模型、移动黄色标线或调整机器结构，应重新标定孔位边界和铣轮锚点；只改变相机视角不影响对应关系。
